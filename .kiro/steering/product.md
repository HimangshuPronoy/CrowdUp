# Product Overview

CrowdUp is a social feedback platform where users can submit and vote on bug reports, feature requests, and complaints about various companies and products. The platform features a podium-style ranking system for top posts, user profiles, messaging, search functionality, and company-specific pages.

## Key Features

- Post creation for bug reports, feature requests, and complaints
- Voting system with podium rankings for top posts
- User profiles and authentication
- Company-specific pages
- Search and trending sections
- Messaging system
- Notification system
